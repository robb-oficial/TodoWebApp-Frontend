About This Not-So-Special Todo App

I made this app to understand the basics of full-stack web programming, using my favorite modern technologies and best practices although I'm pretty sure I failed at that, but I plan to keep improving this little project. Also, I didn't use any AI to generate the code for this app, it helped me better understand the ECharts library and misconceptions about JavaScript/TypeScript but I did not let it generate any code for me. It was slow but I genuinely enjoyed learning and solving every little challenge by myself.
